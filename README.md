# Capitalist ltd Party

Migration from WordPress to a GitHub-managed website.

## Requirements

- Keep capitalistltdparty.com as the public domain.
- Preserve the existing appearance as closely as possible; compare a preview before cutover.
- Retain the WordPress wheel editor and display its wheel on the replacement site.
- Preserve existing page paths, wiki articles, published content, and media.
- Organize Cultural Nation information under ACE, CASA, GA, AME, SEA, and AO.
- Use Rolling Service for the R occupational gate.
- Cultural Nation banner links should open the relevant region, scroll to the entry, and highlight it.

## Current status

Repository initialized. The live site and domain are unchanged.

A preliminary content export contains 285 published page records and 40 published posts. This is not a full WordPress backup: plugin code, database tables, media binaries, theme settings, and Elementor source still require preservation and review.

Before domain cutover, establish a separate HTTPS WordPress origin, validate wheel embedding and editor access, audit memberships/checkout/course functionality, and compare desktop/mobile previews.
